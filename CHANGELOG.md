# Changelog

## Unreleased

### Added

- Complete Neovim colorscheme generated directly from Matugen JSON.
- Automatic reload after ordinary writes and atomic file replacements.
- Light and dark modes, optional transparency and syntax color overrides.
- Contrast correction across editor, cursorline, menu and diff backgrounds.
- Consistent Vim syntax, Treesitter captures and LSP semantic token colors.
- Highlight integrations for Telescope, Neo-tree, blink.cmp and Gitsigns.
- `:MatugenNvimBridgeReload`, Neovim help and `:checkhealth matugen_nvim_bridge`.
- Automated contrast, lifecycle and real Matugen integration tests.
